# TermDesk 移动端生产终端
 
### 核心定位
 
面向数字内容创作者的移动端AIGC生产终端 —— 创作者用手机即可指挥AI Agent完成内容生产工作流（生成网页交互作品、海报素材、短视频脚本与批处理、互动H5），执行在本地沙盒或远程工作站。

安卓端AI开发/创作终端，做本地外壳 + 双运算内核架构：
 
- 本地Termux定制沙盒，脱PC可用
- 连接远程PC/服务器，调用已兼容的各类agent应用内核如codex、workbuddy等
- 模型采用第三方API
 

### 整体架构
 
应用层:
交互UI：Agent对话框、终端面板、文件管理器、任务管理器

连接管理层:
设备绑定、协议调度、双内核切换

封装层（Termux二次封装沙盒）
预装基础环境：Python/Node/常用工具包（提供联网下载渠道，按需下载）
沙盒权限管控：隔离应用目录，限制系统调用

可选运行内核
本地内核：基于Termux二次开发的agent沙盒
远程内核：PC/服务端Agent + 完整执行环境
 

### 核心功能模块
 
1. Agent对话模块：多轮对话、上下文记忆、代码/指令生成、结果高亮

2. 远程终端模块：模拟命令行、历史记录、日志搜索`待定`

3. 文件管理模块：本地/远端目录浏览、文本编辑、双向传输、断点续传

4. 双模式切换：本地远程切换

5. 连接管理：扫码绑定远程设备、TLS加密、断线重连、离线指令缓存
 

### 技术栈`待定`
 
- 前端：Flutter 打包安卓APK；xterm.dart 实现终端组件
- 本地层：Termux 核心二进制预装，定制APT源，按需下载工具包
- 通信层：WebSocket（实时消息/对话） + SSH（终端/文件传输），TLS 1.3加密`待定`
- 模型：接入第三方大模型API（代码生成/通用对话）；可选本地跑0.5B级小模型做意图识别
- 远程端：FastAPI 中转服务 + Docker 执行环境
 
### 备注
 
1. Termux内核，做「预装环境 + 外壳定制」，营造轻量本地agent沙盒
2. APK：只预装基础外壳，提供内核按需在线安装
3. 弱网优化和离线可用性
