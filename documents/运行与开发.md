# 运行与开发

> 命令从仓库根目录执行。当前版本见 [README](../README.md)。本文不包含个人域名、密钥或本机绝对路径。

## 1. 准备电脑代理

要求 Node.js 20+。Windows 是电脑工具的主要宿主；Linux/Android 使用 POSIX 路径，部分系统操作按平台拒绝。

```powershell
npm ci --prefix pc-agent
node pc-agent/src/server.js --host 0.0.0.0
```

默认端口 7420。终端需额外加 `--enable-shell`，启动后在本机访问 `/healthz` 查看是否应答，在 `/pair` 配对手机。

可用参数：

| 参数 | 用途 |
|---|---|
| `--host` / `--port` | 指定监听位置，局域网连接需放行相应端口 |
| `--enable-shell` | 允许远程 shell，权限等同运行代理的用户 |
| `--local` | 手机式本地模式，强制回环地址，关闭中转 |
| `--show-token` | 在本机显示主令牌，勿截图或提交 |

## 2. 配对与连接

电脑浏览器打开 `http://127.0.0.1:7420/pair`，手机相机扫码后交给 TermDesk。地址必须从手机可达；电脑的 `127.0.0.1` 指的是电脑自身，不能直接当成普通手机连接地址。

设备管理可保存多台电脑、切换、暂时断开或解绑。扫码/配对页面包含凭据，不应分享截图。直连配对与中转配对机制不同，以当前页面给出的信息为准。

如果只想开发时联调，可以使用 ADB 端口转发，但它依赖调试连接，不是正式公网访问方式。本轮 Redmi 演示验收的电脑联调通道仅用于验证和传送本机环境。

## 3. 控制文件访问范围

默认允许目录比较宽，启动前可在 PowerShell 中明确指定（多目录用分号）：

```powershell
$env:TERMDESK_ROOTS = 'D:\projects;D:\exchange'
node pc-agent/src/server.js --host 0.0.0.0 --enable-shell
```

选择你自己的存在目录。文件操作校验实际路径与符号链接边界，但 shell 本身仍有宿主用户权限；目录白名单不是任意命令的安全沙盒。

## 4. 外网访问（可选）

公网通过自建 Relay（目标为 RackNerd/Oulu 节点），使用有效 TLS 证书和 wss/https。Cloudflare Tunnel 已移除，旧 --tunnel 参数会报错；不要继续使用旧启动参数。

中转服务在 `relay/`，单独安装依赖和配置；代理仅在明确启用 `TERMDESK_RELAY=1` 时连接它。中转不是局域网和本机使用的必要条件。公网使用受信任的 TLS 通道，并妥善管理凭据。

桌面与 TermDesk.bat 启动时启用已配置 Relay；其客户端配置在运行设备 ~/.termdesk/relay.json，也可用 TERMDESK_RELAY_CONFIG 指定。当前只接一个中转节点，不能把备用 URL 列表当作统一凭据的节点切换。P2P 打洞尚未实现，详见[最新连接与加密说明](连接与内核核查-2026-10-18.md)。

## 5. 登记助手

先在运行设备安装并登录助手。内置接入按实际路径发现；未知品牌可在运行设备的 `~/.termdesk/kernels/` 新增 JSON：

```json
{
  "id": "my-acp-assistant",
  "label": "我的助手",
  "transport": "acp",
  "bin": "node",
  "preArgs": ["/absolute/path/to/assistant.mjs"],
  "args": ["acp"]
}
```

路径替换为该设备上真实存在的入口。`preArgs` 用于运行时脚本；`args` 为 ACP 启动参数。也可用 `TERMDESK_ACP_KERNELS` / `TERMDESK_CLI_KERNELS` 环境登记。CLI 需明确适配契约，未验证时不会被当作可运行助手。

本版不直接运行 `.cmd/.bat`：请登记原生程序或 Node 脚本入口。坏 JSON、缺字段会在 Agent 日志中给出路径和原因。安装后在手机选择器中“重新检测”。

## 6. 手机本机模式

1. 电脑准备兼容运行环境载荷。`pc-agent/tools/build-local-kernel.mjs` 从已有的重定位 Termux bootstrap tar 构建；不会凭空下载/构建完整工具链。
2. 默认输出/读取位置为 `~/.termdesk/local-kernel`，也可指定 `TERMDESK_LOCAL_KERNEL_DIR`。
3. 手机连接电脑后，从“设置 → 运行设备与助手”下载并安装。
4. App 会核对大小、SHA-256，解包并运行健康检查。成功后选择“本机手机”。
5. 此时文件与终端可用；AI 助手需另行安装和配置。不要把“运行环境已安装”当作“模型已可用”。

参考[本地沙盒边界](本地沙盒-隔离边界与资源限制.md)。不要导入别人的模型凭据作为演示环境。

## 7. Android 构建与安装

准备 JDK 17+、Android SDK 35；本轮使用 JDK 21。设置 `JAVA_HOME`、`ANDROID_HOME` 或按本机方式配置 SDK。

```powershell
npm ci --prefix pc-agent
.\android\gradlew.bat -p android :app:testDebugUnitTest :app:assembleDebug
```

APK：`android/app/build/outputs/apk/debug/app-debug.apk`。

```powershell
adb devices -l
adb -s <你的设备序列号> install -r -t android/app/build/outputs/apk/debug/app-debug.apk
```

务必指定目标设备。`-r` 保留数据，签名不一致时停止并确认对应签名的构建；不卸载应用规避冲突。

release 签名配置由使用者在仓库外的 `~/.termdesk/keystore/termdesk-release.properties` 提供，无配置不输出可安装的签名正式包。不要提交密钥和密码。

## 8. 测试边界

```powershell
npm --prefix pc-agent test
.\android\gradlew.bat -p android :app:testDebugUnitTest
```

默认代理测试含语法、契约、状态、帧与假助手端到端；部分条目会因缺载荷或平台不同跳过，日志需如实保留。中转测试需要先 `npm ci --prefix relay`。连接回归不依赖 cloudflared 或真实模型。

`test:live` 是连接现有代理的集成检查集合，不等于许可调用模型。任何真实 prompt 都先按[开发约束](开发约束.md)确认助手与模型。Qoder 的真实 prompt 探针默认关闭；不能以“现在没登录”作为测试不会计费的保证。

### 不调用模型的会话 UI 验证

仓库提供可选的 `pc-agent/tools/ui-demo-assistant.mjs`。它只产生固定中文回复，保留最多 20 条合成会话索引，不读模型账号、不执行工具、不访问网络。它不是内置助手，不会自动出现在任何设备上。

需要在测试设备使用时，将脚本复制到专用演示目录，再显式登记 CLI 契约。示例路径必须替换为该设备的实际绝对路径：

```json
{
  "id": "ui-demo",
  "label": "交互演示（无模型）",
  "transport": "cli",
  "bin": "node",
  "preArgs": ["/absolute/path/to/ui-demo-assistant.mjs"],
  "shim": {
    "newArgs": ["--print"],
    "resumeArgs": ["--print", "--resume"],
    "listArgs": ["--list-sessions"],
    "sessionTitle": "title",
    "sessionCwd": "cwd",
    "sessionUpdatedAt": "updated_at"
  }
}
```

回复会明确写“界面演示 · 未调用模型”。验证完成可删除这份登记；不要据此宣称真实助手已验收。脚本旁的 `.ui-demo-sessions.json` 是运行数据，勿提交。

## 9. 常见问题

| 现象 | 检查方向 |
|---|---|
| 手机连不上 | 电脑是否启动；地址和端口是否可达；防火墙/局域网隔离；设备管理内的具体错误 |
| 新建会话灰色 | 是否已连接；当前设备是否发现可用助手 |
| 助手显示可用却无法回答 | 登录、模型配置、网络、助手原始错误；“可用”先验证入口，不验证服务额度 |
| 本机没有助手 | 手机与电脑安装互不共享；手机环境内另行安装 |
| 保存失败或没确认 | 留在编辑器保留修改，查看权限/存储/连接反馈；勿反复退出丢弃 |
| 更新包无法安装 | 确认包名、版本号、签名一致；保留应用数据 |
| 通知延迟 | 查看系统省电策略、后台/自启动权限；不保证所有 OEM 都持续保活 |
| Android 服务列表不可用 | 这是 Windows 服务能力，手机端应明确提示平台不支持 |
