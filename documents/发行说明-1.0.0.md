# TermDesk v1.0.0

首个正式发行版本。Android 是日常工作入口，Windows 桌面端用于管理代理、设备、助手和会话。

## 本版内容

- 手机端整理工作台、设置及导航，减少重复说明，保护编辑草稿与未保存内容；暂时隐藏不符合手机 Agent 配置目标的电脑 Codex 配置入口。
- 桌面端改为管理控制台，提供概览、设备管理、助手发现、会话查看与控制权状态。
- 修复多客户端连接抢占事件通道、设备吊销后仍在线、运行环境已安装却被网络错误覆盖等问题。
- 保留动态助手发现、重复保存确认、增量同步、文件访问守卫和本机 Agent 内容指纹更新等修复。
- 补齐项目介绍、架构、功能清单、上手说明及验收记录。

## 发布产物与安装

- `TermDesk-1.0.0.apk`：正式签名 Android APK，versionCode 10。仅相同签名可以覆盖升级；现有调试包不能直接用正式包覆盖，不要卸载来绕过冲突。
- `TermDesk-PC-agent-1.0.0.zip`：含代理源码及生产依赖，电脑安装 Node.js 20+ 后运行根目录 `TermDesk.bat`。
- `TermDesk-Desktop-1.0.0-windows-x64.zip`：含桌面程序、Java 运行时及同版本代理；解压后运行 `Start-TermDesk.bat`。仍需 Node.js 20+，默认不自动启动代理。
- `SHA256SUMS.txt`：发布文件校验值。源码由 `v1.0.0` 标签固定。

Windows 程序未做商业代码签名。手机本机运行环境和 AI 助手另行安装，发行包不附带模型账号或密钥。中转、隧道需使用者配置。

## 验证范围

- 本版执行 `npm --prefix pc-agent test`，退出码 0；含多客户端端到端测试 10/10 和中转测试 12/12。
- Android 单测 13 类、116 项、0 失败；正式签名包构建及 release lint 通过。
- Windows `createDistributable` 构建通过，生成自带 Java 运行时的程序目录。
- Redmi 对前序 demo.3 的多端事件、离线反馈、吊销、设置导航做过真机验证，见[多端联动修复验收](多端联动修复验收-2026-10-17.md)。正式版本只调整版本与发行文档，未覆盖手机现有调试安装，也未重新进行完整真机界面验收。
- 测试使用合成协议及假助手，没有调用真实模型。平台专属测试、未开启的真实 Qoder 调用及可选完整载荷哈希仍有明确跳过项；不代表所有助手和平台均已验证。

## 已知边界

本版采用侧载方案，默认 targetSdk 28，以支持私有目录内运行环境；不作为应用商店上架包。ARM64 Android 为本机环境主要验证对象。不同助手的历史恢复、审批和取消能力不一致；手机 Agent 通用配置仍待实现。多手机独立通知确认、按电脑完全隔离的缓存和队列仍需完善。桌面最终改动通过构建及协议验证，未重新打开桌面窗口完整复验。

能力与限制持续维护于[功能清单](功能清单.md)、[架构设计](架构设计.md)和[运行与开发](运行与开发.md)。
