## 第一批：只解决安装、连接、收信

本批完成前，不扩展新内核、P2P、UI 大改或正式发行。建议依次完成 R1 → R2 → R3，再执行 R4。

| 编号/优先级 | 剩余工作 | 可执行验收标准 |
|---|---|---|
| R1 / P0 | 恢复可重复构建并保留性能修复 | 隔离或恢复缺失的 Gradle 缓存，不清理用户工程或手机数据；Android 单测、APK 构建均成功；新增 28 项专项及完整默认 npm 回归结束且退出 0；保留真实跳过项。用修复版读取 600 条历史，重复发现次数不随会话条数增长，读取期间健康请求和心跳能正常响应 |
| R2 / P0 | 查清 Redmi App 连接失败的准确原因 | 记录脱敏的连接阶段、错误类别、关闭码和耗时，区分 DNS、TLS、WebSocket、认证、电脑离线和帧处理；先单独验证 Oulu，暂不自动混入不共享凭据的 LAN 地址。成功后前台持续在线 10 分钟，至少 30 次心跳；3 次断线重连成功；重启 App 后不重新扫码即可连接；失败时显示真实原因，不永久停在“正在连接” |
| R3 / P0 | 完成本会话向手机的真实文字投递 | 在独立且明确标注“Codex 本会话单向投递”的会话中，手机实际显示本会话写下的文字和唯一校验词；正文逐字匹配、有来源和时间；返回列表再打开仍可读，手机断线重连后不重复追加。保存当次真机截图与脱敏收据。禁止用固定演示回复冒充当前会话、用服务器日志代替手机显示或宣称已经双向同步 |
| R4 / P1 | 形成可交付安装包与真机验收记录 | 安装修复版时保留签名和手机数据；从手机拉取安装包核对 SHA-256、版本号、更新时间及内嵌 Agent 指纹，确认不是只编译未安装；记录从“远程电脑 → 添加/选择电脑 → 连接 → 打开消息”的实际步骤和截图。注明 Wi-Fi/移动网络、代理状态及后台限制 |
| R5 / P1 | 收拾测试期间的临时状态 | 区分新增测试绑定和用户原有设备；只清除本轮产生且确认不用的配对记录，保留有效 Redmi 绑定；处理同一 Oulu 地址尾斜杠形成的重复记录。结束测试桥和自有探针，不遗留抢占连接的客户端；凭据只进设备私有存储 |

R3 第一阶段的临时桥只证明单向投递。正式实现应使用经过认证的消息入口及稳定的消息 id，并定义持久化和去重；若要手机回复本 Codex 会话，需要另外设计双向桥，不能默认已有此能力。

## 第二批：连接体验与身份一致性

| 编号/优先级 | 剩余工作 | 验收标准 |
|---|---|---|
| C1 / P1 | 统一 LAN / Relay 认证和网络切换 | 同一设备绑定跨路径可认证；无法做到时明确让用户分别配对，不下发“看起来能切换”的无效备用地址。局域网切中转、中转切局域网各测 3 次，吊销生效、不重复发送、不串历史 |
| C2 / P1 | 简化连接页错误和大字体布局 | 在本次 400dp 宽、1.45 倍字体下，状态、错误及重试无需滚到底才看见；DNS/TLS/凭据失效/电脑离线分别有简明中文提示；日志保留技术详情。空白配对码重连不覆盖永久凭据，二维码不产生多套互相竞争的连接 |
| C3 / P1 | 多设备与后台行为 | 明确当前 Relay 的单在线客户端限制，避免一台手机的重试使另一台掉线；覆盖双手机争用、App 切后台/回前台、息屏 10 分钟、网络切换与在线吊销。区分收到消息、系统通知、用户已读，不承诺系统免打扰下必有提醒 |

## 后续项目缺口

| 编号 | 工作 | 完成判定 |
|---|---|---|
| L1 | 内置 P2P | 有真实认证信令、ICE/STUN/DataChannel；不同 NAT 下能证明业务实际直连，失败正确回中转；覆盖文件、终端、审批，不只连通一个探测包。另行明确服务器 UDP 和带宽预算，不能改动其他服务 |
| L2 | 加密 | 局域网当前为明文，需设计可信证书/设备身份；公网现为分段 TLS，CDN/Relay 可读正文。如实现 E2EE，需覆盖密钥绑定、更新、吊销及正文/附件保护，不能以 TLS 验收替代 |
| L3 | DSH | 使用本机 ASAR 内实际 rc.1 或显式支持的独立安装，验证启动、overlay、连续对话及取消；持久恢复另验。运行包存在不等于 TermDesk 可直接使用；真实模型测试需遵守项目许可边界 |
| L4 | Claude Code / ACP | Claude Code 目前仅动态发现，需选择并实现真实接口；MiMo、Command Code 的 initialize 成功不代表恢复、审批、取消和模型回合都已验收。每种内核按实际版本逐项记录，通过后才开放对应能力 |
| L5 | RackNerd 及节点切换 | RackNerd 仍需迁出 Tunnel；新增独立入口后再验收。两节点身份、吊销和故障切换当前未实现，不把 Oulu 单节点成功写成高可用 |
| L6 | 分发与文档 | Windows dev.2 EXE 已检查载荷，但仍待干净机器安装；Node 20+ 目前仍为外部依赖，安装器未签名。正式发布前同步版本、README、架构图、功能矩阵、安装说明和实际真机证据 |
