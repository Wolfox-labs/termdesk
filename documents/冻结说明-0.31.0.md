# 冻结说明 · TermDesk 0.31.0

> 继承 `0.3.0-demo` 的那五项（主页 / Codex / 已实现且有测试守着的功能 / 终端接管 / PC 端 TermDesk），
> 这一版把它们**接到了唯一入口**上：手机不再直连某台机器，而是连中转，由中转转给各台电脑。
>
> 冻结的含义照旧：下面写"已验证"的都有据可查（命令、脚本、记录），没验的一律列在边界里。

---

## 1 这一版多了什么

| # | 新增 | 为什么 |
|---|---|---|
| 1 | **中转成为唯一入口** | `term.wolfoxlabs.xyz` 曾被两台机器同时声明（本机隧道 + VPS 隧道），Cloudflare 把请求分摊给两个连接器，手机一半的请求落到 relay 上 → 扫码配对报 `invalid credentials`。一条主机名只能属于一台机器，所以入口只能有一个 |
| 2 | **电脑端自助出配对码** | 电脑用自己的节点凭据向 relay 申请一次性码，不需要谁去登服务器；relay 磁盘上只存哈希 |
| 3 | **每台手机一份凭据** | 以前一台电脑只有一个令牌、所有手机共用，"吊销某台"做不到。现在配对即发独立凭据，可单独吊销/移除 |
| 4 | **手机上的电脑列表** | 一台手机可以配多台电脑，各自一份凭据，能切换、能解绑（旧版的单绑定会自动迁成第一条） |
| 5 | **同名不顶人** | 同一台电脑同时只允许一台手机在线：第二台收到关闭码 4409 并自动重试，界面上写明原因，不静默顶掉第一台 |

### 3.2 使用者真机

- 21:57:40 在主力机上完成配对：relay 上出现该手机的独立设备记录，随后使用者确认可用。
- 期间发现并修掉一个真 bug：配对页的令牌框会预填旧凭据，配对成功后再点一次「连接」会把刚拿到的新凭据覆盖成旧的 → 之后一直 `invalid credentials`。现在输入框默认留空（留空＝用已保存的凭据），点「连接」不会覆盖任何东西。
- 同一轮还补上一处设计漏洞：手机在**没连上**的时候解绑，那一帧发不出去，电脑名单不会变，而当时的界面什么也不说。现在界面会明说，并且电脑端 `/devices` 多了「移除」——吊销是让凭据作废，移除是把记录删掉。

## 4 这一版里如实写明的边界

1. **装包不能走中转**：relay 只转发已配对手机的 `/download` `/upload`，未配对的手机拿不到 APK。装/升级只能在同一局域网（`http://<电脑IP>:7420/app.apk`）或 adb。
2. **同一台电脑同时只有一台手机在线**（刻意的：明确拒绝，不静默顶掉）。
3. **手机离线时解绑发不出去**：本地会解绑，但电脑那边的名单不会跟着变，界面会明说这一点；残留记录在电脑的 `/devices` 上点「移除」清掉。
4. **直连（局域网）路径没有单独吊销**：那条路仍是共享令牌。要按台管理就走中转。
5. **Codex 的命令行只能看和终止，不能输入**（app-server 只给输出流与交互记录，写 stdin 的两个入口都要求进程由客户端自己创建）；ACP 内核的命令由我们执行，所以能输入。
6. **不是 PTY，是管道**（代理刻意不带原生依赖），依赖真终端的交互式程序会走非交互分支。
7. **Codex 工具调用**的验收结论沿用 `0.3.0-demo` 那一轮的记录（真模型，一次授权）；本版没有重跑真实模型。
8. **手机沙盒里的 DSH 回合仍为空**（已分包，见 `E:\aiPic\termdesk-handoff\local-sandbox-20261006\`）。
9. **`dsh.wolfoxlabs.xyz` 的公网入口目前是 404**：cloudflared 不再随 TermDesk 启动，那条隧道只剩 VPS 一个连接器，而它的 ingress 只写了 `term.*`。要恢复得给它**单独一条隧道**（同一条隧道两边都挂连接器就会重演第 1 节那件事）。
10. **没有 MSI 安装包**（本机没有 WiX），桌面端交付的是免安装的应用镜像目录。

## 5 怎么跑起来

```powershell
# 电脑端：TERMDESK_RELAY=1，拨出连中转，不再起隧道
双击 TermDesk.bat
#   = node pc-agent\src\server.js --host 0.0.0.0 --enable-shell
#   启动横幅会打印一个配对码与二维码；也可以打开 http://127.0.0.1:7420/pair（每开一次一个新码）

# 桌面窗口（可选）
desktop\TermDesk-Desktop.bat          # 只开窗口
desktop\TermDesk-Desktop.bat -start   # 开窗口并起代理

# 手机端
手机浏览器打开 http://<这台电脑的局域网IP>:7420/app.apk     # 或 adb install -r -t <apk>
```

配对：电脑上打开 `/pair` → 手机扫码 → 手机上出现"已配对的电脑"这一条。
管理：电脑上 `/devices` 看名单、吊销或移除某台手机；手机上在配对页切换/解绑。

前置条件：`%USERPROFILE%\.termdesk\relay.json`（`{ url, nodeId, key, proxy? }`）存在，且这台电脑的 `nodeId` 已在 relay 的 `nodes[]` 里登记（本机是 `workstation`）。
