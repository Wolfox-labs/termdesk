# 待办清单

更新：2026-10-18；源码基线：v1.0.0（f0d4c51）。接替七份旧 TODO、执行计划及交接清单，原文可查 v1.0.0 Git 历史。这里只列仍有效的工作，不继承旧测试结果或模型调用许可。

## 当前方向

- 手机是工作入口；桌面是管理控制台，不再要求完整聊天输入、文件编辑器和终端工作区。
- 使用者的[原始需求文档](移动端agent开发.md)保留原样；当前实现见[功能清单](功能清单.md)。
- 手机需要的是手机端 Agent 配置。旧电脑 Codex 配置入口继续隐藏，通用手机配置暂缓。
- 本轮只整理文件及审查硬编码，不实施下列功能修改；真实模型调用按[开发约束](开发约束.md)另行取得许可。

## 后续设计或明确暂缓

| 手机 Agent 通用配置 | 先明确目标设备、作用域、生效时机；密钥脱敏；不改真实账号配置跑测试 |
