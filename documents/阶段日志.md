### 3. 本阶段修掉的问题（使用者可感知）

1. **点「设置」卡死并闪退**：主线程遍历 7 万条目的沙盒。现在后台线程 + 有界遍历（撞上限会写"显示的是下限"）+ 30 秒缓存；真机 1.2 秒上屏，之后无 ANR。
2. **"手机上没看到任何返回"**：不是渲染问题（假内核全程正常）。真凶是"内核一个字都没产出却静默"，现在会写明"这一轮没有返回任何内容"并附内核原话；同时修了"打开历史必失败"（`resumeVerdict` 越界）。
3. **ACP 流式回答被整条删除**：ACP 的片段**就是**正文（Codex 才是"预览 + 权威项"），两种语义已分开处理。
4. **手机内核表**：9 个内核如实显示（含 4 个"暂不可用"及原因），不再自己编一份。
5. **本地内核装不上/跑不了**：三个真问题——App 进程不能执行私有目录二进制（→ **targetSdk 28**）、toybox tar 拒绝绝对符号链接目标（→ 解包后按 `tar -tvzf` 清单补成相对链接并自证）、"占用"数字曾是没数完的下限（→ 用沙盒预算）。

### 4. 卡在使用者手里的三件事

1. **`qoderclicn login`（或在 CLI 里 `/login`）一次** → 跑一轮即可把 QoderWork 提升为手机可选，并顺手把它的"**完全权限**（`--permission-mode`）与**模型切换**（`-m/--model`、`--list-models`）接进手机（这两项在这个内核上是**真开关**）。
2. **Command Code 要不要实测**：未获授权，按"未授权"处理（manifest 仍是猜测，保持不可选）。
3. **7420 正式实例要不要重启**：它 16:40 启动、跑旧代码，手机装新包后对着它会显示"还没读到这台电脑的内核表"。**一直没动它。**

另有一个待认可的产品决定：**targetSdk 28**（本地内核能在 App 进程里执行的硬前提）。不认可就改成"默认 35 + 本地内核需特殊构建"（`TERMDESK_MODERN_TARGET_SDK=1` 是实现该开关的方式）。
