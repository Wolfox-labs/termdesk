## 5 这一版里如实写明的边界

1. **Codex 的命令行只能看和终止，不能输入。** app-server 提供 `thread/backgroundTerminals/list`（清单）、`item/commandExecution/outputDelta`（实时输出）、`terminalInteraction`（交互记录）与 `backgroundTerminals/terminate`（终止）；但写 stdin 的两个入口（`process/writeStdin`、`command/exec/write`）都要求进程由**客户端自己创建**。ACP 内核相反——命令由我们执行，所以能输入。
2. **不是 PTY，是管道。** Windows 上没有原生模块就拿不到 PTY，而这个代理刻意不带原生依赖。命令能跑、输出能流、stdin 能写，但依赖真终端的交互式程序会走非交互分支。
3. **Codex 工具调用已验收**（第 3.1 节），用的是被授权的 `qwen3.8-flash`；换模型不改变这条结论的覆盖面（管线同一套），但小模型自身的推理质量另说。
4. **DSH 远程内核不可用**（使用者实测）；MiMo 的方法级实测报错；QoderWork 未登录 → 都是如实标注为不可选或受限，没有假装能用。
5. **手机沙盒里的 DSH 回合仍为空**（已分包出去，见 `E:\aiPic\termdesk-handoff\`）。
6. **附件（`+`）本轮未复验**；它的上一轮真机结论见项目记录。
7. **公网通道本轮用的是局域网 + `adb reverse`**，隧道未启动；隧道能力本身没动过。
8. **没有发布签名、没有安装包**（安装包按使用者要求推迟）。

## 7 怎么跑起来

```powershell
# 电脑端（终端默认关闭；开了才有终端与命令执行）
双击 TermDesk.bat
#   = node pc-agent/src/server.js --host 0.0.0.0 --enable-shell --tunnel

# 桌面窗口（可选；-start 会连代理一起起来）
desktop\TermDesk-Desktop.bat          # 只开窗口
desktop\TermDesk-Desktop.bat -start   # 开窗口并起代理

# 手机端
adb install -r -t android\app\build\outputs\apk\debug\app-debug.apk
```

启动报告会打印版号、监听地址、shell 状态、内核表与公网自检结果；手机扫码即可配对。
