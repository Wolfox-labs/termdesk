# 冻结说明 · TermDesk 0.32.0

> 继承 `0.31.0`（中转唯一入口、每台手机独立凭据、电脑端名单）。这一版**没有加新入口，加的是"看得见"与"守得住"**：
> 排队在 UI 上够得着（ACP 也能）、通知在真机上验通并能撤销、会话里能列出一轮产出的文件、
> CI 首跑的前置全部做完，另外多了三道**会自动变红的门**（帧覆盖 / 机器令牌 / 重复分支）。
>
> 冻结的含义照旧：下面写"已验证"的都有据可查（命令、脚本、记录），没验的一律列在边界里。
> **这一版有 4 项是"代码与单测都过、但真机没复验"**（手机在改动过程中从 adb 掉线），它们在第 4 节逐条列明。

---

## 1 这一版多了什么

| # | 新增 | 为什么 |
|---|---|---|
| 1 | **ACP 内核上也能排队** | `chat.send` 在 ACP 是**回合结束**才应答，而发送按钮的 `enabled` 受"发送中"限制 → 整轮按钮是死的，"排队"这个功能在 OpenCode / MiMo / Command Code / Stub 上根本够不着。现在只受"有没有字"限制，"发送中"变成按钮左侧一个小转圈，且只在"回合还没开始"的窗口显示 |
| 2 | **审批通知会被收回** | 审批被回答（本机、电脑端）或超时后，通知栏原本残留"内核在等你的确认"。现在按 `requestId` 对上就撤销；重连时若收到**整份待审列表**，不在其中的也算结清（这一条覆盖"手机不在场时被答掉"的审批） |
| 3 | **时间戳夹掉两侧时钟差** | 通知的 `at` 是**电脑的**时钟。差得多时 Android 会把已发生的事画成"3 分钟后"，现在相差超过 2 分钟就改用"手机收到的时刻" |
| 4 | **会话里列出一轮产出的文件** | 数据源是 DSH 自己记的 `deliverables/presented`（`meta.files[{path,description}]`），不是"扫目录前后对比"——后者会把构建产物也算成产出，还看不见写到工作区外的文件。手机端画成"产出文件"行：文件名 + agent 的原话 + 所在目录，点一下跳到文件区的那个目录（复用会话里已有的 `onOpenFilesAt`） |
| 5 | **通知路径两端各留一行日志** | "通知没出现"这件事有三个长得一模一样的成因（没判定 / 没送到 / 没画）。PC 端打印判定与投递去向，手机端打印收到与"投递 / 不打扰"，一次 `adb logcat -s TermDeskNotify:I` 就能分辨 |
| 6 | **三道会变红的门** | `frame-table-test.js`（三处源码对账：agent 的 38 个 `S2C`、relay 发给手机的 2 个、手机 `when` 的 38 个分支；查重复分支、查只在唯一一处分派、查每个分支真有人发）、`machine-token-test.js`（用空 HOME 真跑一遍助手，禁止工具直接读 `~/.termdesk/token`）、CI 里"出现 `Duplicate branch condition` 即失败" |

## 4 这一版里如实写明的边界

1. **4 项只有单测/编译证据，没有真机复验**（手机在这次改动过程中从 adb 掉线，`adb devices` 为空）：
   - 产出文件行点一下跳转（B2 后半）；
   - 审批通知的撤销（B13）；
   - ACP 上发送按钮的可用性（B12）；
   - "断链时手机不会自己醒"这半条（B11）——已证明"帧到了就会画"，未证明反向。
   这四条在有真机时应当**一次过完**，见 `后续任务.md` 顺序建议第 1 条。
2. **表驱动重写没做**（B15 后半）：门做好了并已验证会红，但把 38 个分支改成 `mapOf` 表还没做——`auth.ok`
   分支里有一个**非局部 `return`**（退出 `onMessage`），搬进 lambda 要改语义，而现在没有真机复验整条帧路径。
3. **CI 仍未真跑**：首跑的前置已做完（无 token 的 e2e 会打印 skip 并退出 0；重复分支会失败），等解挂。
4. **"这个会话内总是允许"是内核自己的语义**：TermDesk 只把内核给的 optionId 原样回给它。假内核（stub）不记这个选择，
   所以它每轮都问；真实内核记不记得，是各家自己的事。
5. **双模式一致性 / 弱网自愈（B16）与体验项 B1/B3/B4 未做**。
6. 其余边界沿用 `0.31.0`：装包不能走中转、同一台电脑同时只有一台手机在线、手机离线时解绑发不出去、
   Codex 命令行只能看与终止、不是 PTY、`dsh.wolfoxlabs.xyz` 仍是 404、没有 MSI 安装包。

## 5 怎么跑起来

与 `0.31.0` 相同（见 `冻结说明-0.31.0.md` 第 5 节）：电脑端双击 `TermDesk.bat`（`TERMDESK_RELAY=1` 时拨出连中转），
桌面窗口可选，手机装 `http://<电脑IP>:7420/app.apk` 或 adb 安装。

想复现本轮的真机结论（不花额度）：

```powershell
# 1) 起一个带假内核的代理，并让回合能自己跑完（不用真人点权限）
$env:TERMDESK_ACP_KERNELS = '[{"id":"stub","label":"Stub kernel (free)","bin":"C:\\Program Files\\nodejs\\node.exe","args":["E:\\aiPic\\termdesk\\pc-agent\\tools\\fake-acp-agent.mjs"]}]'
$env:FAKE_ACP_SKIP_PERMISSION = '1'
node pc-agent\src\server.js --host 127.0.0.1 --port 7420

# 2) 手机接上后（adb reverse tcp:7420 tcp:7420），看两端的话
adb logcat -s TermDeskNotify:I          # 手机：收到 / 投递 / 不打扰 / 撤销
# 电脑端同一时刻会打印：notify n-x <kind> → 客户端在线，直接送出｜没有客户端，暂存
```
