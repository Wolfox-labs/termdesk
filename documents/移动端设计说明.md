# 移动端设计与交互说明

> 1.0.0，2026-10-17。设计约定与本轮实现对应；最新修复和验证范围见[多端联动验收](archive/2026-10/多端联动修复验收-2026-10-17.md)，早期演示场景见[原验收记录](archive/2026-10/演示版验收-2026-10-17.md)。

## 1. 信息架构

底部保留四个高频入口：**工作台、会话、文件、终端**。系统与设置放在左上菜单，设备管理在右上。设置主页及子页、会话详情和键盘输入时收起底部栏，保护阅读及输入空间。

工作台按任务顺序组织：

1. 运行位置：远程电脑 / 本机手机。
2. 当前状态：已连接的设备，或需要处理的连接问题。
3. 工作上下文：助手与工作目录。
4. 主操作：全宽“新建会话”。
5. 工具与最近会话：便于检查文件、进入终端和接回工作。

大字号允许纵向滚动，不靠缩小系统字体挤进首屏。首页只承担选择和继续工作，完整资源详情放到系统页。

会话页的“+”是新建入口，先询问**助手与工作目录**再创建：默认带入首页的常设选择，可从已发现的工作区、Agent 根目录或手输路径中改。首页的选择是“下一件事”的默认，不替代这一次的决定；创建时选中哪个，就按哪个建，不因首页尚未解析出默认助手而静默丢弃。

## 2. 视觉约定

- 继续沿用现有 Monokai 深浅主题，浅色和深色都从同一主题变量读取颜色。
- 主操作使用实心按钮；可选运行位置显示选中状态；说明与辅助信息降低层级。
- 运行上下文用一个分组容器承载，减少散落的“更换”“刷新”重复入口。
- 操作行使用图标、文本和可点击区域共同表达，图标不单独代替含义。
- 目标与助手选择声明可访问的单选语义；重要图标有内容说明。
- 文本使用系统字号，长路径和标题按用途省略或换行，不显示无意义的 `null`。
- 瞬时提示位于底部导航上方；键盘出现时输入仍可达。

## 3. 状态与下一步

| 状态 | 页面表达 | 可做的下一步 |
|---|---|---|
| 已连接 | 明确设备 / 本机沙盒就绪 | 选助手、目录，进入工具 |
| 正在连接 | 简短连接提示，缓存仍可读 | 等待或打开设备管理 |
| 无法连接 | 单处说明“暂时无法连接” | 查看设备管理的具体错误 |
| 没有助手 | “未检测到可用助手”，新建禁用 | 重新检测或查看设置说明；仍可用文件和终端 |
| 能力不支持 | 明确平台或助手原因 | 不提供会静默失败的可用按钮 |
| 空历史 | 说明首次工作会出现在这里 | 连接后开始会话 |
| 加载失败 | 保留失败原因与重试路径 | 重新加载，而非伪装成空列表 |

“已安装运行环境”“已发现助手”“模型已配置”“一次操作已完成”是不同状态，不互相代替。

## 4. 返回与工作保护

系统返回按当前界面逐层退出：弹窗、抽屉/侧栏、会话或文件模式、子页、分区，最后才到应用外。键盘首先交给系统收起。

文件编辑有三个明确选择：保存并离开、取消、放弃修改。保存时等待设备确认，失败或超时保留编辑内容；离线时保存不可点击。相同文案的连续保存结果必须各自交付，不能因状态值相等丢失。

终端首次进入可以懒创建；使用者主动关闭后，切页再回来保持关闭。只有“新建终端”才重新建立会话。关闭运行中的会话或进程涉及实际任务，需保留相应确认与失败反馈。

## 5. 会话与输入

- 对话使用文档式正文，以“你 / 助手”标注角色，不使用聊天气泡；不改写助手原文。两行以上的引擎备注可点击展开。
- 会话详情优先给正文和输入区留空间，主导航在此模式收起。
- 草稿按运行目标、电脑/会话作用域保存，离开页面不自动发送。
- 消息提交与服务端确认分开，离线队列保留未确认内容。
- 权限弹窗能延后，让使用者先阅读背景；延后不等于批准，超时仍按既定策略处理。
- 主控状态由 Agent 判断，观察者的写入得到明确拒绝；不能仅靠禁用按钮保障权限。
- 助手选择器读取当前设备能力，说明是否支持历史延续；不把规划字段变成可编辑功能。

## 6. 手机运行环境

设置里展示用途、安装阶段及实际失败原因。连接电脑时也能找到安装入口，避免必须先切换到未就绪的手机目标才能下载。

下载后校验大小和指纹，健康检查成功才显示已安装。本机模式下安装成功会继续启动代理，避免成功后还要猜测切换步骤。运行环境不包含已配置的模型账号；真实助手需使用者另行准备。

## 7. 反馈文案

首页使用“助手”“运行设备”“工作目录”，减少实现术语。技术错误留在设备管理与诊断页，首页提供简短结论和可操作入口。

成功说明完成了什么，例如“已保存 demo-save.txt”；失败说明原因和当前内容是否保留。不将“未找到”用于已经找到但不可执行的文件。

本轮文案整理遵循以下规则：

- 首页直接展示设备、助手、目录和操作，移除“继续你的工作”等开场句及重复功能介绍。
- 空状态写实际状态，如“暂无会话”；需要处理时再给下一步。不承诺未验证的登录、恢复或配置能力。
- 面向使用者统一称“助手”“这台手机”“远程电脑”；协议名、路径及错误码保留在确有必要的位置。
- 按钮写动作，如“选择目录”“继续编辑”“稍后处理”；删除、密钥、未保存修改等后果仍需明确。
- 离线发送明确写“重连后自动发送”，避免缩短文案后隐藏自动操作。

设置中的电脑 Codex 配置入口已隐藏。使用者最新要求是手机端 Agent 配置，现有电脑 Codex 编辑器不符合此要求；保留已有实现供后续评估，不作为可用入口。手机端 Agent 的配置项目、保存和生效方式待设计。

## 8. 真机验证尺度

本轮设备 Redmi K90 Pro Max，1200×2608，density 480，字体 1.45 倍。保留原系统设置，检查首屏、滚动、键盘、保存确认、导航和状态栏对比。

不能由此宣称所有安卓机型、小屏、横屏、屏幕阅读器及长时间后台均通过。下一轮优先补：TalkBack 焦点、横屏与旋转保草稿、上传跨页归属、弱网中重复点击、长文本/长路径及多设备控制状态。
