# 功能清单

> 1.0.0，2026-10-17。已实现表示存在产品路径，实际验证范围另列；不代表所有设备和助手都已实测。

## 手机端功能

| 模块 | 当前能力 | 条件与边界 |
|---|---|---|
| 工作台 | 选择设备、助手、目录；新建；最近工作 | 新建需连接及可用助手；缓存记录可离线查看 |
| 导航 | 工作台、会话、文件、终端底部入口；菜单内系统与设置 | 设置及子页、会话详情、键盘输入时收起底部导航 |
| 设备 | 多电脑保存、切换、配对、断开、解绑确认 | 直连与中转的凭据机制不同 |
| 本机环境 | 下载、SHA-256 校验、解包、健康检查 | 需提供兼容载荷；AI 助手另行安装 |
| 助手发现 | 当前设备发现、刷新、不可用原因 | 发现入口不代表已登录或模型可用 |
| 会话 | 创建、流式文字、工具与推理、取消、关闭 | 事件和取消方式取决于适配器 |
| 历史 | 目录组织、打开、能力允许时继续 | CLI 不一定提供正文；DSH 重启恢复未承诺 |
| 草稿 | 保存输入及附件引用 | 按目标与会话作用域保存；仍需扩展进程重建验证 |
| 离线 | 缓存历史、发送队列、回包确认 | 远程缓存及队列尚未完全按每台电脑隔离 |
| 权限请求 | 审批、拒绝、延后、超时处理 | 关闭弹窗不自动批准；超时按默认策略处理 |
| 控制权 | 主控/观察者、接管与写入检查；按接收者更新权限 | 运行中回合不允许其他设备强抢 |
| 多端观察 | 已认证客户端同时接收会话事件；终端按连接订阅输出 | 桌面观察不消费手机通知；离线缓存与并发编辑仍有边界 |
| 设备吊销 | 拒绝新认证，并立即断开该凭据的现有连接 | 文件与运行环境 HTTP 请求使用同一凭据校验；其他设备保持连接 |
| 同步 | 打开、重连、回前台时全量校准 | 最近最多 1,200 事件；无分钟全文轮询；无游标增量恢复 |
| 文件 | 浏览、搜索、新建、改名、删除确认 | 在允许目录内校验名称和真实路径 |
| 传输 | 上传、下载、进度与结果 | 受网络、手机存储与内容类型影响 |
| 编辑 | 多行文本、保存、未保存离开确认 | 保存确认超时保留当前内容；不是代码 IDE |
| 预览 | 文本及部分文档/媒体路径 | 不承诺所有 Word/PDF 都能完整排版预览 |
| 终端 | 持久会话、输入、输出、打断、清屏、切换、关闭 | 电脑需开 shell；手机需安装运行环境 |
| 会话终端 | 助手命令与关联输出 | 由助手能力决定，不能接管任意外部终端 |
| 系统 | CPU、内存、磁盘、进程、Windows 服务 | Android 数据受限；服务明确提示平台不支持 |
| 外观 | 深/浅/跟随系统；字号跟随系统 | 本轮检查 Redmi 1.45 倍字体，非无障碍认证 |
| 后台 | 前台服务、通知、后台权限指引 | 受 Android/OEM 省电策略影响 |
| 版本 | 设置内版本；协议兼容检查 | App 与嵌入代理一起构建，载荷单独发布 |

## 助手接入

| 接口 | 代表实现 | 已有路径 | 不能统一承诺的能力 |
|---|---|---|---|
| app-server | Codex | 原生 thread、历史、恢复、事件、配置 | 安装/登录/模型条件需助手自身满足 |
| SDK | DeepSeek Harness | 同一运行期连续交互、流式结果 | 代理重启后的原生恢复未开放 |
| ACP | OpenCode、MiMo、自定义登记 | 会话、更新、发现到的模型与模式 | 依实际协议实现；输入模态发现尚未实现 |
| CLI shim | 有适配契约的 CLI | 打印模式、事件、会话标识与声明的恢复 | 未验证契约不提供可用入口；不保证历史正文 |

`native / acp / shim / unsupported` 是接入层级，不是能力排行榜。运行设备的注册表决定启动方式；`contract.js` 和 `manifest.js` 描述能力。

## 配置支持状态

| 状态 | 含义 |
|---|---|
| `supported` | 有实现路径，仍需满足设备和助手条件 |
| `discovered` | 来自内核元数据，不表示任意值均可写入 |
| `planned` | 路线声明，发现或写入链路未完成，不可据此生成可用按钮 |
| `unsupported` | 当前接入不支持 |

Codex 有服务商、模型、推理强度及上下文配置路径，但手机设置中的电脑 Codex 编辑入口已按最新要求隐藏；手机端 Agent 配置待设计，不将前者当作后者交付。ACP 模型/模式以会话发现为准。最大输出、完整输入/输出模态编辑仍属规划。无适配器条目不声明配置作用域。

## 代理、网络与桌面

| 组成 | 状态 | 边界 |
|---|---|---|
| WebSocket 指令与事件 | 已实现 | 版本协商、认证；本身不是加密隧道 |
| HTTP 文件与载荷 | 已实现 | 认证访问；公网使用可信 TLS 通道 |
| 局域网直连 | 已实现 | 防火墙和网络隔离由部署环境决定 |
| Cloudflare 隧道 | 可选 | 需工具和配置；临时地址可能变化 |
| 中转服务 | 可选 | 独立部署、设备配对与反向连接；默认关闭 |
| 桌面窗口 | 已有 | 控制代理和看状态，不是手机功能复刻 |
