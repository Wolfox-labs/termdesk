# 硬编码修复验收

日期：2026-10-18；分支：codex/hardcoding-project-report；开发版本：1.0.1-dev.1。用户授权后，由三位 GPT-6 Luna 子代理分工修复，主代理复核、集成和操作设备。本文接续[只读审查](硬编码审查-2026-10-18.md)，不改写原审查的历史状态。

## 改动及边界

| 项目 | 处理结果 | 验证 |
|---|---|---|
| 手机 DSH 预设 | LocalAgent 不再注入维护者个人 provider/model | Android 单测与构建，源码核查 |
| DSH 路由 | provider/model 明确配置；第三方要求 endpoint/API/key-env；拒绝不一致和非法值；不修改 DSH 自有配置 | 路由、配置生成和 ChatManager 拒绝用例 |
| DSH 能力 | 移除固定百万上下文、128k 输出和图像能力；YAML 安全转义 | 25 项 DSH 回归；发布 SDK 0.2.1-rc.2 类型静态核对，不是实际模型认证 |
| Windows OpenCode | PATH 原生入口、npm package.bin 和标准安装目录；移除个人 D 盘路径 | Windows 隔离入口夹具；直接 cmd/bat 仍明确拒绝 |
| 宿主工具 | Node 与 taskkill 从环境/宿主 PATH 发现；无 taskkill 时使用 JDK 进程树 API | 路径与资源定位单测；仍只停止本窗口拥有的进程 |
| 窗口 | 初始和最小尺寸受可用工作区约束 | 尺寸单测；本轮原生大窗口实际打开，窄屏人工体验未覆盖 |
| 载荷构建 | 必须明确输入 tar，支持参数/环境变量；缺少输入时先报错 | 新构建参数回归纳入默认套件 |
| 审批探针 | 脚本相对路径、临时目录、真实权限响应/去重/完成断言 | 新审批往返回归纳入默认套件 |
| 分发与 CI | 显式 JDK 21；随 app image 附同版本 Agent 与生产依赖 | 本地桌面构建和预检；未运行远端 CI 或正式安装器 |
| JVM 启动 | 修复 java.net.http、java.instrument、jdk.unsupported 缺失 | jdeps、随包 JVM 实际类加载、原生窗口成功打开及五张新截图 |

DSH 移除了隐式默认路由，因此之前依赖个人预设的环境必须显式配置，不能把这个变更解释为“自动读取所有 DSH 配置”。安装和登录状态也不由静态 schema 检查证明。
