# 开发约束（由使用者设定，不是建议）

> 这份文件是硬约束。任何在 TermDesk 上工作的 agent（包括并行的多个）都必须遵守，
> 且不得因为"测试需要"而放宽。违反过一次，记录在此。

## 1 真实模型调用必须先获得许可

**任何会真正打到模型上的调用，都要先问使用者。** 包括：

- 通过 `chat.send` / ACP `session/prompt` / `codex exec` / shim CLI 发出的提示
- 任何"看起来很小"的冒烟测试
- 免费模型（`*-free`）：免费不等于无需许可，它仍然是真实调用

不需要许可的（默认可做）：协议握手、`session/new`、`session/list`、`session/load`、
`session/set_model`、纯函数测试、静态检查、读取本地文件与进程、真机 UI 操作
（点按、截图、注入**合成**事件）。

## 2 只能在许可的 agent 内使用许可的模型

许可是按 **(agent, 模型)** 这一对给的，不是按模型名给的。

| 模型 | 许可的 agent | 说明 |
|---|---|---|
| `qwen3.8-flash` | **仅 Codex** | 使用者原话："我说的 qwen 仅允许在 codex 内调用，不允许在其他 agent 内调用" |

因此：**不得**把 Codex 许可过的模型拿到 OpenCode / MiMo Code / Qoder / Command Code
等其它内核里去跑，哪怕模型名一样、哪怕只是测试。

## 3 事故记录

| 时间 | 事实 | 后果 |
|---|---|---|
| 2026-10-05 | 在 **OpenCode** 里用 `opencode/qwen3.8-flash` 跑了一次 ACP 端到端验证（使用者只授权了 Codex 内的 qwen） | 一次短回合，中途已终止；属于未经许可的花费 |

## 4 代码层面的对应约束

- `TERMDESK_ACP_MODEL` 这类"默认模型"开关**由机器所有者设置**；agent 不得为了测试去设置它，
  也不得在任何脚本/文档里用它推荐具体付费模型。
- 仓库里已有的默认模型（例如 DSH 路由的 `TERMDESK_CHAT_MODEL`）属于**使用者自己发起对话时的默认值**，
  不是 agent 的测试入口：agent 不得借用它来跑验证。
- 需要验证真实回合时，先向使用者确认 agent + 模型，再执行；验证完在提交信息里写明用了什么。
